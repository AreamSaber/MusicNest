## 项目简况

- **项目名称**：鸿音管家（HarmonySound）
- **项目类型**：计算机本科毕业设计
- **技术栈**：HarmonyOS (ArkTS/ArkUI) + Vue 3 + Spring Boot 3 + MySQL 8.0 + Redis 7.x
- **终端覆盖**：鸿蒙 App（C端用户）+ Web 管理后台（B端员工/管理员）
- **开发工具**：DevEco Studio + VS Code + IntelliJ IDEA
